3. Execution Order
   1. Data Acquisition
      • Run data_acquisition_api.ipynb to download API data.
      • Run data_acquisition_scraping.ipynb to scrape Wikipedia data.

   2. Data Cleaning
      • Run data_cleaning.ipynb to clean all CSV files.

   3. Data Integration
      • Run data_integration.ipynb to merge cleaned datasets and generate final CSVs.

   4. Data Storage
      • Run mongodb.ipynb to populate the MongoDB database f1_2025.

4. Output
   - Clean and integrated CSV files:
      • In data_cleaning: races.csv
      • In data_integration: circuits.csv, constructors.csv, drivers.csv, results.csv
   - MongoDB database: f1_2025
